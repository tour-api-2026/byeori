한국 전통문화 여행 가이드 · Android 앱 (com.byeori.app)

전국의 관광 명소와 전통 공연·축제 정보를 한곳에 모아 지도에서 바로 찾아볼 수 있는 앱입니다.

주요 기능

  • 국악·전통무용·마당극·지역 축제 등 전통을 주제로 한 공연과 행사 모아보기
  • 현재 위치를 중심으로 주변 관광지·문화시설·공연장·음식점을 지도에서 찾기
  • 주소·운영시간·연락처·사진·평점을 한 화면에서 확인, 한복 혜택이 있는 곳은 별도 표시
  • 가고 싶은 곳을 담아 하루 일정을 짜고 이동 경로 확인
  • 다녀온 곳에 별점과 후기 남기기

장소와 공연을 찾아보는 기능은 로그인 없이도 모두 이용할 수 있습니다.
