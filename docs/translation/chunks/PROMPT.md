# 번역 세션 지시서

이 파일은 **새 세션에 그대로 붙여 쓰는 작업 지시서**다. 레포의 다른 파일을 읽지 않아도
한 청크를 끝낼 수 있게 필요한 것을 전부 여기 담았다.

## 세션에 줄 말

> `docs/translation/chunks/PROMPT.md` 를 읽고, `docs/translation/chunks/chunk-NN-....csv` 의
> `en`·`ja`·`zh` 칸을 채워서 같은 경로에 덮어써 줘.

`NN` 만 바꿔 가며 세션마다 한 파일씩 맡긴다. 파일끼리 의존이 없어 순서·동시성 제약이 없다.

## 무엇을 하는가

한국 전통문화 여행 앱 **벼리**가 외국인 관광객에게 보여 줄 장소·행사 이름을
영어·일본어(일본 한자)·중국어(간체)로 옮긴다. 카드에 붙는 **라벨**이다 — 문장이 아니다.

## 건드리지 말 것

```csv
kind,id,ko,en,ja,zh
venue,1360,강남,,,
```

- `kind`·`id`·`ko` 는 **절대 바꾸지 않는다.** 되돌려 넣을 때 `kind`+`id` 로 행을 찾고,
  `ko` 가 DB 의 현재 값과 다르면 그 행은 버려진다.
- 행을 지우거나 순서를 바꾸거나 새로 추가하지 않는다. **행 수가 그대로여야 한다.**
- `en`·`ja`·`zh` 세 칸만 채운다.
- 쉼표·따옴표가 든 이름이 있다. CSV 인용을 지킨다(`"쌀롱드무지끄, The last story Ⅱ"`).

## 번역 규칙

고유명사가 핵심이다. **뜻으로 풀면 안 된다.**

- **영어** — 국어의 로마자 표기법 + 보통명사.
  경복궁 → `Gyeongbokgung Palace`, 북촌한옥마을 → `Bukchon Hanok Village`,
  국립중앙박물관 → `National Museum of Korea`.
  공식 영문명이 있으면 그것을 쓴다(기관·브랜드는 홈페이지 표기를 따른다).
- **일본어·중국어** — 로마자가 아니라 **그 이름의 실제 한자**를 쓴다.
  경복궁 → `景福宮` / `景福宫`. 보통명사는 번역하고(公園/公园, 寺, 市場/市场, 博物館/博物馆),
  한자가 없는 고유어는 일본어는 가타카나, 중국어는 통용 음역을 쓴다.
- **한글 음절을 남기지 않는다.** `en`·`ja`·`zh` 어느 칸이든 완성형 한글(가~힣)이 남으면
  그 칸은 넣을 때 버려진다 — 번역하지 못해 원문을 그대로 둔 것과 구별할 수 없기 때문이다.
  단 **낱자(`ㄱ`, `ㅅㅏㄹㅁ` 처럼 자모만 쓴 것)는 그대로 남긴다.** 제목에 낱자를 디자인으로
  쓴 공연이 있고(`제5회 ㄱ기억연극전`), 그건 고유명사라 번역문에도 남아야 한다.
- 짧게. 설명을 덧붙이지 않는다. `(서울)` 같은 괄호 부분은 빼지도 더하지도 않는다.

### 모르면 비워 둔다

**한자를 모르면 추측하지 말고 그 칸을 비운다.** 틀린 한자는 비어 있는 것보다 나쁘다 —
비어 있으면 한국어로 떨어져 보이지만, 틀린 한자는 아무도 틀린 줄 모르고 그대로 쓰인다.
비운 칸은 야간 AI 배치가 나중에 채우거나, 다음에 사람이 채운다. 부분만 채워도 된다.

### 실제로 틀렸던 것

| 한국어 | 틀린 번역 | 맞는 것 |
|---|---|---|
| 창경궁 | Changdeokgung (창덕궁) | Changgyeonggung / 昌慶宮 / 昌庆宫 |
| 건청궁 | Gyeongchun | Geoncheonggung / 乾淸宮 |
| 경희궁 | 京熙宮 | 慶熙宮 / 庆熙宫 |
| 국립고궁박물관 | 国立高宮博物館 | 国立古宮博物館 |
| 개운사 | 开云寺 | 开运寺 |
| 경리단길 | 京畿段街 | 経理団通り / 经理团路 |

서울 5대 궁(**경복궁·창덕궁·창경궁·덕수궁·경희궁**)은 이름이 비슷해 서로 바뀌기 쉽다.
사람 이름과 절 이름도 한자를 확인하지 않으면 자주 틀린다.

### 이 청크에서 자주 나오는 것

- **장소 청크**(`seoul-core`/`seoul-rest`/`jeju`) — 공원·사찰·시장·전시관·거리 이름이 많다.
  `...공원` → `Park` / `公園` / `公园`, `...사` → `Temple` / `寺`, `...시장` → `Market` / `市場` / `市场`.
  행정동 이름이 붙은 것(`대모산도시자연공원`)은 고유부는 로마자·한자로, 보통명사부는 번역한다.
- **행사 청크**(`perf-live`) — 공연 제목이다. 부제·회차·장소 표기가 섞여 있다.
  `제12회` → `12th` / `第12回` / `第12届`, `[대학로]` 같은 장소 표기는 그대로 옮긴다.
  이미 영어인 제목(`The last story Ⅱ`)은 영어 칸에 그대로 두고, 일·중은 그 영어를 유지한다.

## 끝내고 확인할 것

1. 행 수가 원본과 같다 (`wc -l`).
2. `ja`·`zh` 칸에 한글이 없다.
3. `kind`·`id`·`ko` 가 한 글자도 바뀌지 않았다 — `git diff` 로 그 세 칸이 변하지 않았는지 본다.

다 되면 파일을 같은 경로에 덮어쓰고, **채운 행 수와 비워 둔 행 수**를 보고한다.

## 되돌려 넣기 (운영자용 — 세션이 할 일이 아니다)

API 서버 호스트에서 레포 루트로 가서, `--apply` 없이 먼저 돌려 숫자를 본다.

```bash
python3 scripts/import-translations.py docs/translation/chunks/chunk-NN-....csv
python3 scripts/import-translations.py docs/translation/chunks/chunk-NN-....csv --apply
```

- `반영` 이 기대한 수와 맞고, `이름이 바뀜`·`행 없음`·`한글 섞임` 이 0 에 가까운지 본다.
- 넣은 행은 `tr_source='HUMAN'` 이 되어 야간 AI 배치가 다시 번역하거나 덮어쓰지 않는다.
- 잘못 넣었으면 CSV 를 고쳐 다시 `--apply` 한다(같은 `kind`+`id` 행이 새 값으로 덮인다).
