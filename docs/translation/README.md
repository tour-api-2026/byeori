# 번역용 CSV

장소·행사·코스의 한국어 이름을 영어·일본어·중국어(간체)로 번역하기 위한 작업 파일.

## 파일

| 파일 | 행수 | 무엇 |
|---|---|---|
| `translate-priority.csv` | 3,261 | **먼저 할 것** — 큐레이션 코스 14, 코스에 담긴 장소 58, 아직 안 끝난 행사 3,189 |
| `translate-course-desc.csv` | 14 | 코스 설명문(이름이 아니라 문장이라 따로) |
| `translate-all.csv` | 47,500 | 전체 |

`translate-priority.csv` 가 사용자 눈에 **지금 바로** 보이는 것들이다. 루트 탐색 탭은
통째로 그 14개 코스이고, 홈과 전통 테마 탭은 안 끝난 행사를 보여 준다. 나머지 장소
34,670건은 지도를 그 자리까지 움직여야 보인다.

## 모양

```csv
kind,id,ko,en,ja,zh
course,1,경복궁 별빛야행 풀코스,"","",""
perf,9981,브루노 마스 내한공연,"","",""
venue,12,경복궁,"","",""
```

`kind` 와 `id` 는 **건드리지 않는다** — 되돌려 넣을 때 이것으로 행을 찾는다.
`ko` 도 그대로 둔다. `en` · `ja` · `zh` 세 칸만 채운다.

## 번역 규칙

고유명사가 핵심이다. 뜻으로 풀면 안 된다.

- **영어**: 국어의 로마자 표기법 + 보통명사.
  경복궁 → `Gyeongbokgung Palace`, 북촌한옥마을 → `Bukchon Hanok Village`,
  국립중앙박물관 → `National Museum of Korea`.
  공식 영문명이 있으면 그것을 쓴다.
- **일본어·중국어**: 로마자가 아니라 **그 이름의 실제 한자**를 쓴다.
  경복궁 → `景福宮` / `景福宫`. 한자를 모르면 추측하지 말고 비워 둔다 —
  틀린 한자는 비어 있는 것보다 나쁘다. 아무도 틀린 줄 모른다.
- 카드에 붙는 라벨이다. 문장이 아니라 짧게.

### 특히 조심할 것

실제로 틀렸던 사례다.

| 한국어 | 틀린 번역 | 맞는 것 |
|---|---|---|
| 창경궁 | Changdeokgung (창덕궁) | Changgyeonggung / 昌慶宮 |
| 건청궁 | Gyeongchun | Geoncheonggung / 乾淸宮 |
| 경희궁 | 京熙宮 | 慶熙宮 / 庆熙宫 |
| 국립고궁박물관 | 国立高宮博物館 | 国立古宮博物館 |
| 개운사 | 开云寺 | 开运寺 |
| 경리단길 | 京畿段街 | 経理団通り / 经理团路 |

서울 5대 궁(경복궁·창덕궁·창경궁·덕수궁·경희궁)은 이름이 비슷해 서로 바뀌기 쉽다.
사람 이름과 절 이름도 한자를 확인하지 않으면 자주 틀린다.

## 되돌려 넣기

채운 CSV 를 그대로 주면 `kind` + `id` 로 짝지어 DB 에 넣는다. 빈 칸은 건너뛴다 —
일부만 채워 와도 그만큼만 반영되고, 나머지는 한국어가 그대로 나간다.
