### 서비스 개요

> 벼리는 전국의 전통·문화 관광지와 전통 테마 행사를 한곳에서 찾고, 나만의 여행 루트로 엮을 수 있는 모바일 앱입니다. 한국관광공사 OpenAPI의 전국 관광지·문화시설·음식점 정보와 축제/행사 정보를 기반으로, 고궁·한옥·국악·민속 등 전통 테마 콘텐츠를 별도로 선별해 제공합니다. 현재 위치 기반 '내 주변' 지도, 장소·행사 상세, 즐겨찾기, 여행 일정(루트) 구성, 이용자 리뷰·장소 등록 기능을 갖추고 있습니다.

## 5. 기능설명서 〔지정 양식에 옮겨 작성〕

### 5-1. 서비스 소개
- **서비스명**: 벼리
- **서비스 유형**: 앱(Android)
- **서비스 개요**: 위 2번 개요 참조
- **주제 선정 이유**:
  > 관광 정보 서비스는 많지만 '전통'이라는 테마로 장소와 행사를 함께 엮어 보여주는 서비스는 드뭅니다. 고궁·한옥·국악 공연처럼 여행자가 실제로 찾고 싶어 하는 전통 콘텐츠는 관광지 정보와 공연·축제 정보가 서로 다른 곳에 흩어져 있어, 하나의 여행 일정으로 묶기 어렵습니다. 벼리는 한국관광공사 OpenAPI의 전국 관광지·축제 데이터를 중심으로 전통 테마 콘텐츠를 선별·통합해, "무엇을 볼지"부터 "어떤 순서로 다닐지"까지 한 앱에서 끝내도록 했습니다.
- **서비스 핵심기능**: 아래 5-3 참조
- **대표 이미지 1장 / 상세 이미지 3~5장**: 〔앱 스크린샷 필요 — 홈, 내 주변 지도, 전통 테마 행사 목록, 장소 상세, 여행 루트〕

### 5-2. 지역 특화 서비스 〔해당 없음〕
전국 단위 서비스이므로 미해당(가점 2점 대상 아님).

### 5-3. 서비스 핵심 기능별 흐름도 (최대 5개)

| # | 핵심 기능 | 설명 | 흐름 |
|---|---|---|---|
| 1 | 전통 테마 행사 탐색 | 국악·전통/역사 축제 등 전통 행사 1,155건을 별도 선별해 제공 | 홈 → 전통 테마 행사 섹션 → 전체보기 → (진행 중/예정) 목록 → 상세/예매 링크 |
| 2 | 내 주변 지도 | 현재 위치 기준 주변 관광지·문화시설·맛집·카페를 카테고리 마커로 표시 | 탭 '내 주변' → 위치 권한 → 지도 → 마커 선택 → 장소 상세 |
| 3 | 장소 탐색·검색 | 키워드(문화/카페/체험/맛집)·지역·검색어로 전국 29,466건 탐색 | 홈/검색 → 필터 선택 → 목록 → 장소 상세(주소·전화·이미지·리뷰) |

| 5 | 리뷰·장소 등록 | 이용자가 리뷰·사진을 남기고 새로운 장소를 등록 | 로그인 → 장소 상세 → 리뷰 작성 / 마이페이지 → 장소 등록 |

### 5-6. 서비스 차별성 & 발전계획

**차별성**
1. **전통 테마 자동 선별**: 장르(국악)·제목 키워드(고궁·한옥·민속·판소리 등)·기관 분류를 조합해 흩어진 데이터에서 전통 콘텐츠 1,155건을 자동 분류. 기관명 오탐('문화재단'→'문화재')까지 걸러내는 규칙을 적용.
2. **장소와 행사의 통합**: 관광지 정보(공사 OpenAPI)와 공연·축제 정보를 같은 여행 일정 안에서 함께 다룸.
3. **여행 루트 중심 UX**: 단순 정보 조회를 넘어 담기 → 일정 구성 → 지도 경로까지 이어지는 흐름.
4. **무중단 업데이트**: OTA(EAS Update) 도입으로 스토어 심사 없이 개선 사항을 당일 반영.

**발전계획**
1. 지역 특화 확장 — 시군구 단위 전통 코스 큐레이션(경주·전주·안동 등)
2. 다국어(영문) 지원으로 외래 관광객 대상 확대
3. 전통 체험 예약 연계 및 리뷰 데이터 기반 개인화 추천
4. iOS 출시(Sign in with Apple·인앱 계정 삭제 요건 대응 후)

## 결정 필요 사항 (제출 전)

1. **테스트 계정 방식** — SNS 연동(카카오)으로 제출할지, 지정 규격 계정(`openapi@…/2026openapi!`)을 새로 만들지. 후자는 이메일 로그인 기능 확장이 필요(현재는 관리자 전용).
2. **로컬 DB 저장 방식** — 주최 측은 실시간 호출을 강력 권고하며, 로컬 DB 방식은 **호출 이력이 없으면 불이익**. 벼리는 일 1회 동기화 방식이므로 (a) 호출 이력이 남는 점을 근거로 그대로 제출, (b) 일부 기능을 실시간 호출로 전환, (c) `tourapi@knto.or.kr`에 사전 문의 중 선택 필요.
3. **Play Store 등록 일정** — 스토어 등록 완료가 제출 전제조건. 추가 기간 제공 없음.
