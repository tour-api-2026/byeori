# 다국어 구현 계획 (2/2 — 분류값과 콘텐츠)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 서버가 주는 한국어 — 분류값, 장소·행사 이름, 상세 설명, 큐레이션 코스 — 를 선택한 언어로 보여 주고, AI 루트도 그 언어로 만든다.

**Architecture:** 분류값은 가짓수가 적어 앱 사전으로 바꾼다. 이름과 설명은 `gpt-4o-mini` 로 번역해 DB 컬럼에 저장하고, 서버가 `Accept-Language` 를 보고 해당 컬럼을 `name` 에 담아 내려준다. 사용자 요청 경로에 AI 호출은 없다 — 번역은 매일 동기화 뒤 배치로만 돈다.

**Tech Stack:** Spring Boot, PostgreSQL, Flyway, OpenAI `gpt-4o-mini`(이미 사용 중), TypeScript / React Native (Expo SDK 54).

**Spec:** `docs/superpowers/specs/2026-10-20-i18n-design.md` (4~6단계)

**앞선 계획:** `docs/superpowers/plans/2026-10-20-i18n-app.md` (1~3단계, PR #88 로 완료·운영 반영). 앱의 번역 엔진·사전·`useT()`·`Accept-Language` 헤더는 이미 있다. 이 계획은 그 위에 올린다.

## Global Constraints

- **`apps/app/package.json` 과 `apps/app/app.json` 을 바꾸지 않는다.** 둘 다 Expo 지문에 들어가, 바뀌면 이미 설치된 앱에 OTA 가 닿지 못하고 스토어 재심사가 된다. 앱에 npm 패키지·테스트 러너를 더하지 않는다.
- 언어는 네 가지: `ko` · `en` · `ja` · `zh`(중국어 간체). `Accept-Language` 로 이 네 값을 그대로 주고받는다. 서버는 아는 네 값이 아니면 한국어로 본다.
- 앱 사전 키는 **네 파일 모두**에 넣는다(`ko.ts`·`en.ts`·`ja.ts`·`zh.ts`), 한 줄에 하나 `  'key.name': 'value',` 작은따옴표. `node apps/app/scripts/i18n-check.mjs` 가 본다.
- **한국어 값은 바꾸지 않는다.** 카테고리·지역·장르는 DB 값이자 API 필터 값이다. 번역하는 것은 표시 라벨뿐이다.
- **V27 은 이미 운영에 적용된 마이그레이션이다. 한 글자도 고치지 않는다** — Flyway 체크섬은 주석까지 포함하고 `validate` 가 기본으로 돌아, 바꾸면 다음 기동이 실패한다. 새 마이그레이션은 **V28 부터**.
- 번역이 없으면 **한국어로 떨어뜨린다.** 화면이 비거나 키 문자열이 보이면 안 된다.
- **사용자 요청 경로에 AI 호출을 넣지 않는다.** 예외는 상세 설명 하나이며, 그것도 처음 한 번만 부르고 저장한다(Task 9).
- 백엔드 시험은 Gradle 테스트로 덮는다. 앱은 테스트 러너가 없으므로 `node apps/app/scripts/i18n-check.mjs` 와 `npx tsc --noEmit` 으로 본다.

## Review Focus

1. **아직 번역되지 않은 행** — 동기화 직후, 배치가 돌기 전에 조회하면 한국어 이름이 나가야 한다. 빈 문자열이나 `null` 이 나가면 목록에 이름 없는 칸이 생긴다. (Task 6)
2. **이름이 바뀐 행** — 공사가 이름을 고치면 다시 번역해야 하고, 그대로면 영원히 다시 번역하지 않아야 한다. 해시 비교가 뒤집히면 매일 전량을 다시 번역해 비용이 수백 배가 된다. (Task 5)
3. **`Accept-Language` 가 모르는 값이거나 없을 때** — `de`, `zh-Hans-CN`, 빈 값, 헤더 자체가 없는 경우 전부 한국어로 떨어져야 하고, 500 이 나면 안 된다. (Task 6)
4. **AI 응답이 부분적으로 깨졌을 때** — 묶음 100건 중 3건만 형식이 어긋나면 그 3건만 건너뛰고 97건은 저장해야 한다. 전부 버리면 영원히 수렴하지 않는다. (Task 5)
5. **번역 컬럼을 검색에 넣은 뒤의 한국어 검색** — `경복궁` 으로 검색하던 사람이 계속 찾을 수 있어야 한다. 조건을 OR 로 넓히다 기존 결과가 바뀌면 회귀다. (Task 7)

`apps/app/src/lib/i18n/labels.ts` — 기존 `kakaoCategoryLabel` 바로 아래에:

```ts
/**
 * 행사 장르·코스 테마·댓글 태그의 표시 이름.
 *
 * 값 자체는 한국어다 — 서버가 그 문자열로 주고 우리는 비교에만 쓴다. 사전에 없으면
 * **한국어 값을 그대로** 보여 준다. 장르는 외부 데이터(KOPIS)라 언제든 새 값이 생길 수
 * 있는데, 그때 `genre.새것` 같은 키가 화면에 뜨는 것보다 한국어가 낫다.
 */
const passthrough = (t: TFn, prefix: string, value: string) => {
  const key = `${prefix}.${value}`;
  const out = t(key);
  return out === key ? value : out;
};

export const genreLabel = (t: TFn, value: string) => passthrough(t, 'genre', value);
export const themeLabel = (t: TFn, value: string) => passthrough(t, 'theme', value);
export const tagLabel = (t: TFn, value: string) => passthrough(t, 'tag', value);
```

기존 `categoryLabel`·`regionLabel`·`kakaoCategoryLabel`·`areaLabel` 도 같은 모양이다. 네 함수가 이미 같은 본문을 반복하고 있으므로, 이 과제에서 **전부 `passthrough` 를 쓰도록 모은다** — 일곱 개가 제각각 복사본을 갖는 것은 다음 사람이 한 곳만 고치고 나머지를 놓치는 자리다.

```java
/**
 * 추천이 뜬 이유. 코드와 값을 나눠 담는다.
 *
 * 전에는 서버가 "관심 주제 · 문화" 처럼 **문장을 조립해서** 내려보냈다. 앱은 그것을 한
 * 덩어리로 받으므로 사전으로 가를 수 없어, 다국어로 만들 수 없었다. 코드만 주면 앱이

 *
 * param 은 코드마다 뜻이 다르다 — 거리(km), 남은 날수, 분류, 장르. 서식(소수점·단위)은
 * 언어마다 다르므로 서버는 숫자를 문자열로만 넘기고 꾸미지 않는다.

public record FeedReason(String code, String param) {

    public static FeedReason nearby(double km) {
        return new FeedReason("NEARBY", String.format("%.1f", km));
    }
    public static FeedReason favoriteRegion() { return new FeedReason("FAVORITE_REGION", null); }
    public static FeedReason favoriteTopic(String topic) { return new FeedReason("FAVORITE_TOPIC", topic); }
    /** 분류·장르를 그대로 보여 주는 경우. 앱이 제 분류값 사전으로 번역한다. */
    public static FeedReason category(String category) { return new FeedReason("CATEGORY", category); }
    public static FeedReason genre(String genre) { return new FeedReason("GENRE", genre); }
    public static FeedReason recommended() { return new FeedReason("RECOMMENDED", null); }
    public static FeedReason ongoing() { return new FeedReason("ONGOING", null); }
    public static FeedReason startsToday() { return new FeedReason("STARTS_TODAY", null); }
    public static FeedReason startsInDays(long days) {
        return new FeedReason("STARTS_IN_DAYS", String.valueOf(days));
    }
    public static FeedReason upcoming() { return new FeedReason("UPCOMING", null); }
}
```

```java
private FeedReason performanceReason(Performance p, LocalDate today, double match) {

    if (start != null && !start.isAfter(today)) return FeedReason.ongoing();
```

```ts
/**
 * 추천이 뜬 이유를 문장으로.
 *
 * CATEGORY·GENRE 는 값 자체가 문구다 — 이미 가진 분류값 사전을 태우고, 따로 키를 두지

 * 문자열을 준다. 코드 이름이 화면에 뜨는 것만은 막는다.
 */
export function feedReasonText(t: TFn, code: string, param?: string | null): string {
  if (code === 'CATEGORY') return param ? categoryLabel(t, param) : '';
  if (code === 'GENRE') return param ? genreLabel(t, param) : '';
  const key = `feed.reason.${code}`;
  const out = t(key, { p: param ?? '' });
  return out === key ? (param ?? '') : out;
}
```

```java
package com.byeori.global.i18n;

import java.util.Locale;

/**
 * 지원 언어. Accept-Language 로 이 네 값을 그대로 주고받는다.
 *
 * BCP-47 꼬리표(zh-Hans-CN 같은)를 해석하지 않는다 — 우리 앱은 늘 네 값 중 하나를
 * 보내고, 그 외는 브라우저가 제멋대로 보낸 것이라 어느 언어를 원하는지 알 수 없다.
 * 모르면 한국어다. 던지지 않는다 — 헤더 하나 때문에 500 이 나면 안 된다.
 */
public enum Lang {
    KO, EN, JA, ZH;

    public static Lang of(String header) {
        if (header == null || header.isBlank()) return KO;
        return switch (header.trim().toLowerCase(Locale.ROOT)) {
            case "en" -> EN;
            case "ja" -> JA;
            case "zh" -> ZH;
            default -> KO;
        };
    }
}
```

```java
package com.byeori.domain.translation;

import com.byeori.global.i18n.Lang;
import com.byeori.global.external.OpenAiClient;
import com.fasterxml.jackson.databind.JsonNode;
import java.util.*;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

/**
 * 장소·행사 이름을 묶음으로 번역한다.
 *
 * 고유명사라 로마자 표기법이 중요하다 — 경복궁은 "Blessing Palace" 가 아니라
 * "Gyeongbokgung Palace" 다. 프롬프트에 규칙과 대조표를 넣어 잡는다.
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class TranslationClient {

    private final OpenAiClient openAi;

    private static final String SYSTEM = """
        You translate Korean place and event names for a travel app.
        Rules:
        - Use the official Revised Romanization of Korean for proper nouns,
          then add the English common noun: 경복궁 -> "Gyeongbokgung Palace",
          북촌한옥마을 -> "Bukchon Hanok Village", 국립중앙박물관 -> "National Museum of Korea".
        - Keep well-known official English names when they exist.
        - Do not translate a proper noun into its literal meaning.
        - Keep it short: this is a label on a card, not a sentence.
        - Return every input exactly once, echoing the input in "src".
        """;

    /** 원문 → 번역. 실패하거나 AI 가 빠뜨린 항목은 결과에 없다. */
    public Map<String, String> translate(Lang lang, List<String> names) {
        if (lang == Lang.KO || names.isEmpty()) return Map.of();
        String user = "Target language: " + lang.name() + "\n" + String.join("\n", names);
        try {
            JsonNode res = openAi.completeJson(SYSTEM, user, "translations", SCHEMA);
            return parse(res, names);
        } catch (Exception e) {
            // 한 묶음이 실패해도 다음 묶음은 돌아야 한다. 못 한 행은 다음 배치에서 다시 집는다.
            log.warn("번역 실패 lang={} 건수={} : {}", lang, names.size(), e.toString());
            return Map.of();
        }
    }

    /**
     * 응답에서 쓸 수 있는 짝만 고른다.
     *
     * 요청하지 않은 원문은 버린다 — AI 가 지어낸 짝을 저장하면 엉뚱한 행에 번역이 붙는다.
     * 빈 번역도 버린다. 셋 중 하나가 깨져도 나머지 둘은 살린다.
     */
    static Map<String, String> parse(JsonNode res, List<String> asked) {
        Map<String, String> out = new LinkedHashMap<>();
        if (res == null || !res.isObject()) return out;
        JsonNode items = res.get("items");
        if (items == null || !items.isArray()) return out;
        Set<String> want = new HashSet<>(asked);
        for (JsonNode it : items) {
            String src = it.path("src").asText(null);
            String tr = it.path("out").asText(null);
            if (src == null || tr == null || tr.isBlank() || !want.contains(src)) continue;
            out.put(src, tr);
        }
        return out;
    }

    private static final Map<String, Object> SCHEMA = Map.of(
            "type", "object",
            "properties", Map.of("items", Map.of(
                    "type", "array",
                    "items", Map.of(
                            "type", "object",
                            "properties", Map.of("src", Map.of("type", "string"),
                                                 "out", Map.of("type", "string")),
                            "required", List.of("src", "out"),
                            "additionalProperties", false))),
            "required", List.of("items"),
            "additionalProperties", false);
}
```

```java
package com.byeori.domain.translation;

import com.byeori.domain.performance.*;
import com.byeori.domain.venue.*;
import com.byeori.global.i18n.Lang;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

/**
 * 번역이 없거나 이름이 바뀐 행을 찾아 번역해 저장한다.
 *
 * 매일 동기화 뒤에 한 번 돈다. **사용자 요청 경로에서는 절대 부르지 않는다** — 응답
 * 시간이 AI 에 묶인다.
 *
 * 처음 한 번은 장소 34,728 + 행사 12,633 을 전부 번역한다(언어당 약 $1). 그 뒤로는
 * 새로 들어온 행사만 주 670건쯤이라 월 몇십 원이다.
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class TranslationBatch {

    /** 한 번에 AI 에 보내는 이름 수. 너무 크면 응답이 잘리고, 너무 작으면 호출이 잦다. */
    private static final int CHUNK = 100;
    /** 한 번 돌 때 처리할 최대 행 수. 첫 전량 번역이 하룻밤에 안 끝나도 다음 날 이어간다. */
    private static final int MAX_PER_RUN = 5_000;

    private final VenueRepository venueRepo;
    private final PerformanceRepository perfRepo;
    private final TranslationClient client;

    public void run() {
        for (Lang lang : List.of(Lang.EN, Lang.JA, Lang.ZH)) {
            translateVenues(lang);
            translatePerformances(lang);
        }
    }

    @Transactional
    void translateVenues(Lang lang) {
        List<Venue> todo = venueRepo.findNeedingTranslation(lang.name(), MAX_PER_RUN);
        int done = 0;
        for (List<Venue> chunk : partition(todo, CHUNK)) {
            Map<String, String> got = client.translate(lang, chunk.stream().map(Venue::getName).toList());
            for (Venue v : chunk) {
                String tr = got.get(v.getName());
                if (tr == null) continue;                 // 이번에 못 한 것은 다음 배치가 집는다
                v.applyTranslation(lang, tr);
                v.markHash(hashOf(v.getName()));
                done++;
            }
        }
        if (done > 0) log.info("장소 번역 lang={} {}건", lang, done);
    }

    @Transactional
    void translatePerformances(Lang lang) {
        List<Performance> todo = perfRepo.findNeedingTranslation(lang.name(), MAX_PER_RUN);
        int done = 0;
        for (List<Performance> chunk : partition(todo, CHUNK)) {
            Map<String, String> got = client.translate(lang, chunk.stream().map(Performance::getTitle).toList());
            for (Performance p : chunk) {
                String tr = got.get(p.getTitle());
                if (tr == null) continue;
                p.applyTranslation(lang, tr);
                p.markHash(hashOf(p.getTitle()));
                done++;
            }
        }
        if (done > 0) log.info("행사 번역 lang={} {}건", lang, done);
    }

    /** 이름의 sha256(16진수 64자). 이름이 바뀐 행만 다시 번역하려고 쓴다. */
    public static String hashOf(String name) {
        try {
            byte[] d = MessageDigest.getInstance("SHA-256")
                    .digest(name.getBytes(StandardCharsets.UTF_8));
            StringBuilder sb = new StringBuilder(64);
            for (byte b : d) sb.append(String.format("%02x", b));
            return sb.toString();
        } catch (Exception e) {
            throw new IllegalStateException("SHA-256 을 쓸 수 없다", e);
        }
    }

    private static <T> List<List<T>> partition(List<T> src, int size) {
        List<List<T>> out = new ArrayList<>();
        for (int i = 0; i < src.size(); i += size) out.add(src.subList(i, Math.min(i + size, src.size())));
        return out;
    }
}
```

```java
public String titleIn(Lang lang) {
    String t = switch (lang) { case EN -> titleEn; case JA -> titleJa; case ZH -> titleZh; case KO -> null; };
    return (t == null || t.isBlank()) ? title : t;
}

/** 선택한 언어의 설명. 번역이 없으면 한국어 원본. */
public String descIn(Lang lang) {
    String d = switch (lang) { case EN -> descEn; case JA -> descJa; case ZH -> descZh; case KO -> null; };
    return (d == null || d.isBlank()) ? description : d;
}
```

코스 응답 DTO 의 `from` 이 `Lang` 을 받아 `titleIn`·`descIn` 을 쓰게 하고, 컨트롤러가
`@RequestHeader(value = "Accept-Language", required = false)` 로 받아 `Lang.of(...)` 로 넘긴다.

`systemPromptNew()` 가 `Lang` 을 받게 하고 **끝에** 아래를 붙인다. 기존 지시(`[며칠짜리인지]`

```java
/** 언어 지시. 루트의 글은 번역하되 장소 이름은 한국어를 유지한다. */
private static String languageClause(Lang lang) {
    if (lang == Lang.KO) {
        return "\n\n[언어]\n제목과 설명을 한국어로 쓴다.";
    }
    String name = switch (lang) {
        case EN -> "English";
        case JA -> "Japanese";
        case ZH -> "Simplified Chinese";
        case KO -> "Korean";
    };
    return "\n\n[Language]\n"
         + "Write the route title and every description in " + name + ".\n"
         + "But keep the Korean place names exactly as given — do not translate or romanize them.\n"
         + "The traveller needs them to match the signs and to show a taxi driver.\n";
}
```

`systemPromptNew(Lang lang)` 의 반환값 끝에 `+ languageClause(lang)` 을 붙인다.

장소 이름을 한국어로 두는 것이 핵심이다. 외국인이 현장에서 간판을 맞추거나 택시 기사에게
보여 주려면 한국어 이름이 필요하다. 화면에는 앱이 **번역된 DB 값**으로 바꿔 보여 주므로
(Task 6) 사용자가 한국어를 읽을 일은 없다.

```java
}
```
